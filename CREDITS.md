# Credits

This mod is built on Origin HeartGold and everything that went into it. The credits below follow the [Origin HeartGold credits page](https://pokemonoriginheartgold.com/credits/) and its patch notice (reviewed 14 October 2026). Names are given exactly as credited there.

This mod is free and will stay free: no money is involved, and there are no donation prompts. hg-engine allows its code and assets to be used only on those terms.

## This mod

- **Lugiling sprites**: AI-generated pixel art, cleaned up and fitted to the DS sprite format for this mod.
- **Shadow Lugia**: recoloured from Lugia's existing sprites.
- **Tools used**: [xdelta3](https://github.com/jmacd/xdelta-gpl) (patches), the [pret/pokeheartgold](https://github.com/pret/pokeheartgold) decompilation (character map and engine reference), and [BizHawk](https://github.com/TASEmulators/BizHawk) / melonDS (testing).
